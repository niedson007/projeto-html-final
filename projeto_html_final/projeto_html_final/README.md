# Projeto HTML - Desenvolvimento Front-End para Web

## Sobre o projeto

Este projeto foi desenvolvido para a disciplina de Desenvolvimento Front-End para Web.

O projeto tem como objetivo aplicar os conhecimentos de HTML estudados durante as aulas, utilizando diferentes elementos para criar páginas interligadas.

O conteúdo foi baseado no projeto inicial, que apresentava informações pessoais, estudos, hobbies e uma página de contato. O projeto foi ampliado para incluir novos conteúdos e recursos de HTML.

## Tecnologias utilizadas

* HTML5
* VS Code

O projeto foi desenvolvido somente com HTML, sem utilização de CSS ou JavaScript.


## Conteúdos utilizados

Durante o desenvolvimento foram utilizados diversos elementos do HTML5, incluindo:

* Estrutura básica de HTML;
* Cabeçalhos e parágrafos;
* Listas ordenadas e não ordenadas;
* Links entre páginas;
* Imagens;
* Tabelas;
* Formulários;
* Campos obrigatórios;
* Campos com placeholder;
* Campo de data;
* Campo para envio de arquivo;
* Campo de cor;
* Datalist;
* Details e Summary;
* Áudio;
* Vídeo;
* Figure e Figcaption;
* Iframe;
* Blockquote;
* Mark;
* Abbr;
* Del e Ins;
* Progress;
* Meter.

## Estrutura semântica

As páginas utilizam elementos semânticos do HTML5 para organizar o conteúdo:

* `<header>` - cabeçalho;
* `<nav>` - menu de navegação;
* `<main>` - conteúdo principal;
* `<section>` - seção de conteúdo;
* `<article>` - conteúdo independente;
* `<aside>` - conteúdo complementar;
* `<footer>` - rodapé.

## Navegação

Todas as páginas possuem um menu de navegação, permitindo acessar as diferentes partes do projeto por meio de links.

## Recursos multimídia

O projeto possui arquivos de áudio e vídeo armazenados localmente nas pastas `audio` e `video`.

Também são utilizadas imagens armazenadas na pasta `img`.

## Formulário

A página de contato possui um formulário com diferentes tipos de campos, incluindo nome, e-mail, telefone, data, arquivo e cor.

Também foram utilizados os atributos `required` e `placeholder` para melhorar o preenchimento do formulário.

## Objetivo da atividade

O objetivo principal é demonstrar o conhecimento dos recursos apresentados nas aulas de HTML e aplicar esses conhecimentos na criação de um projeto com várias páginas interligadas.
