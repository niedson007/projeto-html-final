Curiosidades sobre HTML

1. HTML é uma linguagem de marcação

HTML é utilizado para estruturar o conteúdo de páginas web por meio de elementos e tags.

2. As tags possuem diferentes funções

Cada elemento pode ter uma função específica. Por exemplo, <h1> representa um título principal e <p> representa um parágrafo.

3. HTML pode trabalhar com multimídia

O HTML possui elementos próprios para inserir imagens, áudios e vídeos em páginas web.

Você sabia?

O que significa HTML?

HTML significa HyperText Markup Language .

Para que serve o header?

O elemento <header> representa normalmente o cabeçalho de uma página ou seção.

Para que serve o nav?

O elemento <nav> representa uma área destinada à navegação entre páginas ou partes importantes de um site.

Para que serve o footer?

O elemento <footer> representa o rodapé de uma página ou seção.

Curiosidade sobre semântica

Neste projeto, elementos como <header>, <nav>, <main>, <section>, <article>, <aside> e <footer> foram utilizados para organizar o conteúdo.

A estrutura semântica ajuda a identificar a função de cada parte da página.
