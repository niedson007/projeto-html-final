Bem-vindo ao meu projeto!

Este é o meu projeto utilizando HTML. Aqui são apresentadas informações sobre mim, meus estudos, meus hobbies e meus interesses.

Este projeto foi desenvolvido como atividade da disciplina de Desenvolvimento Front-End para Web.

Sobre o projeto

O objetivo é praticar a criação de páginas, links, listas, tabelas, formulários e elementos semânticos.

O projeto utiliza somente HTML, sem CSS e sem JavaScript.

Informação

Use o menu acima para navegar por todas as páginas.

O que foi utilizado?

Durante a construção do projeto foram utilizados diferentes recursos do HTML, desde elementos básicos até elementos semânticos e multimídia.

  • Estrutura semântica;
  • Links e navegação entre páginas;
  • Listas;
  • Tabelas;
  • Formulários;
  • Imagens;
  • Áudio;
  • Vídeo;
  • Elementos interativos;
  • Marcação avançada de texto.

HTML semântico

Uma das características deste projeto é a utilização de elementos semânticos para organizar o conteúdo das páginas.

Entre eles estão: <header>, <nav>, <main>, <section>, <article>, <aside> e <footer>.

O que este projeto demonstra?

O projeto demonstra como é possível criar um site com várias páginas utilizando somente HTML.

As páginas possuem uma estrutura organizada e estão conectadas por meio de links, permitindo uma navegação entre diferentes conteúdos.

Informação importante

Este projeto foi desenvolvido sem CSS e sem JavaScript, conforme solicitado na atividade.

Como funciona o menu?

O menu presente no cabeçalho permite acessar as diferentes páginas do projeto. Cada opção possui um link para uma página HTML específica.

Onde estão os arquivos multimídia?

As imagens ficam na pasta img, os arquivos de áudio ficam na pasta audio e os vídeos ficam na pasta video.
