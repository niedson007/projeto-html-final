Meu interesse por tecnologia

A tecnologia é uma área que desperta meu interesse porque está presente em diferentes atividades do dia a dia e permite criar soluções para diferentes necessidades.

Neste projeto estou tendo contato com recursos de desenvolvimento web e aprendendo como estruturar páginas utilizando HTML.

O que é HTML?

HTML é uma linguagem de marcação utilizada para estruturar conteúdos de páginas web.

No desenvolvimento deste projeto estou aprendendo a utilizar títulos, parágrafos, listas, tabelas, links, imagens, formulários e elementos semânticos.

O HTML é a base principal deste projeto.

Recursos de HTML utilizados

  • Estrutura básica de uma página;
  • Meta tags;
  • Títulos e parágrafos;
  • Listas;
  • Links;
  • Imagens;
  • Tabelas;
  • Formulários;
  • Áudio e vídeo;
  • Elementos semânticos.

Elementos semânticos

Uma das partes importantes deste projeto é a utilização de elementos semânticos para organizar melhor cada página.

Elemento Função
header Representa o cabeçalho.
nav Representa a área de navegação.
main Representa o conteúdo principal.
section Organiza uma seção temática.
article Representa um conteúdo independente.
aside Apresenta conteúdo complementar.
footer Representa o rodapé.

O que estou praticando?

  1. Organização de páginas HTML;
  2. Criação de links entre páginas;
  3. Utilização de elementos semânticos;
  4. Criação de formulários;
  5. Inserção de imagens e arquivos multimídia;
  6. Organização de arquivos em pastas.

Organização do projeto

Para manter os arquivos organizados, o projeto foi dividido em diferentes pastas.

  • html/ - páginas HTML;
  • img/ - imagens;
  • audio/ - arquivos de áudio;
  • video/ - arquivos de vídeo.

Você sabia?

Qual é a diferença entre HTML e CSS?

O HTML é utilizado para estruturar o conteúdo. O CSS é utilizado para definir a aparência e o estilo.

Por que utilizar HTML semântico?

Os elementos semânticos ajudam a identificar a função de cada parte da página e deixam a estrutura do documento mais organizada.

Minha evolução no projeto
