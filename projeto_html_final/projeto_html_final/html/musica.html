Meu interesse por música

A música faz parte do conteúdo deste projeto e também pode acompanhar diferentes momentos do dia.

Nesta página foi utilizado um arquivo de áudio local para demonstrar o recurso de reprodução de música em HTML.

Áudio do projeto

O projeto possui um arquivo de áudio armazenado na pasta audio.

Utilize os controles abaixo para reproduzir o áudio:

Sobre o áudio

  • Formato: MP3
  • Tipo: Áudio local
  • Localização: Pasta audio
  • Reprodução: Controles do navegador

Como o áudio foi inserido?

Para inserir o áudio, foi utilizada a tag <audio> junto com o atributo controls.

O elemento <source> informa ao navegador onde está localizado o arquivo de áudio e qual é o seu tipo.

Organização do arquivo

O arquivo de áudio utilizado nesta página está separado das páginas HTML para manter a organização do projeto.

  • html/ → páginas do site;
  • img/ → imagens;
  • audio/ → arquivos de áudio;
  • video/ → arquivos de vídeo.

Curiosidade sobre HTML

Para que serve o atributo controls?

O atributo controls faz com que o navegador mostre os controles de reprodução do áudio, como reproduzir, pausar e controlar o volume.

O áudio precisa estar na internet?

Não. Neste projeto, o arquivo de áudio é local e está armazenado dentro da pasta audio.

Música e lembranças

A música pode estar relacionada a momentos, emoções, lembranças e interesses pessoais.

Neste projeto, o áudio escolhido também representa uma preferência pessoal apresentada em outras páginas.

O áudio é reproduzido diretamente pelo navegador.
