Quem sou eu?

Meu nome é Niedson. Sou estudante e estou desenvolvendo meus conhecimentos na área de tecnologia.

Atualmente estou aprendendo a criar páginas para a web utilizando HTML e conhecendo diferentes recursos que podem ser utilizados na construção de um site.

Este projeto representa uma parte do meu processo de aprendizado e permite colocar em prática os conhecimentos adquiridos durante as aulas.

Minha relação com a tecnologia

Tenho interesse em tecnologia e estou buscando conhecer melhor o desenvolvimento de páginas e sistemas.

Durante este projeto estou aprendendo como organizar informações utilizando diferentes elementos do HTML.

Entre os recursos que estou praticando estão textos, listas, tabelas, formulários, imagens, links e elementos semânticos.

Sobre este projeto

Esta página faz parte de um site composto por várias páginas HTML conectadas por meio de um menu de navegação.

Cada página possui um assunto específico. Por isso, informações sobre estudos, hobbies, objetivos e outros assuntos podem ser encontradas nas páginas correspondentes.

O projeto foi desenvolvido utilizando somente HTML, sem CSS e sem JavaScript.
