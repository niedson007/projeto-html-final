Objetivo do projeto

Este projeto foi desenvolvido para colocar em prática os conhecimentos aprendidos durante as aulas de Desenvolvimento Front-End para Web.

O site foi construído utilizando HTML e possui várias páginas conectadas por meio de links de navegação.

O projeto foi desenvolvido sem CSS e sem JavaScript.

Organização do projeto

Os arquivos foram separados em pastas para facilitar a organização e a localização dos conteúdos.

Pasta Conteúdo
html/ Páginas do projeto
img/ Imagens utilizadas
audio/ Arquivo de áudio
video/ Arquivo de vídeo

Estrutura semântica

As páginas utilizam elementos semânticos para organizar o conteúdo e identificar a função de cada parte da página.

Entre os elementos utilizados estão:

  • <header> - cabeçalho;
  • <nav> - navegação;
  • <main> - conteúdo principal;
  • <section> - seção temática;
  • <article> - conteúdo independente;
  • <aside> - conteúdo complementar;
  • <footer> - rodapé.

Detalhes do desenvolvimento

Por que o projeto foi dividido em várias páginas?

A divisão permite organizar melhor os conteúdos e separar cada assunto em uma página específica.

Por que utilizar pastas?

As pastas ajudam a separar páginas, imagens, áudios e vídeos, deixando o projeto mais organizado.

O projeto utiliza CSS?

Não. O projeto foi desenvolvido utilizando somente HTML, conforme a proposta da atividade.

Meu aprendizado

Durante o desenvolvimento do projeto, diferentes recursos de HTML foram utilizados para construir e organizar as páginas.

O projeto também permitiu praticar a criação de links, organização de arquivos e utilização de elementos semânticos e multimídia.

Progresso do desenvolvimento: 85%.

O que foi mais importante?

Organizar o conteúdo é uma parte importante da criação de qualquer projeto web.

Neste projeto, a organização das páginas e dos arquivos ajudou a deixar o site mais estruturado.

Resultado

O resultado é um site composto por várias páginas HTML conectadas entre si e organizadas em diferentes pastas.

Cada página possui uma função própria e contribui para a apresentação do projeto como um todo.
